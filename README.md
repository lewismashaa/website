# Kamaa's Chips Inn & Kuku Inn

A simple restaurant landing page for Kamaa's Chips Inn & Kuku Inn, located at Ichung'wa Stores, Kikuyu.

## Features
- Menu section
- Contact and location section
- WhatsApp ordering link
- Responsive layout

## Run locally
Open `index.html` in a browser, or serve the folder with a simple local web server.
